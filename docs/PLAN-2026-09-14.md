# dsh-bio-graft 深化开发计划：从「能跑」到「genie 的契约化基因编辑域插件」

> **For Hermes:** 用 `subagent-driven-development` 逐任务执行；每个任务独立 commit；每阶段结束跑该阶段「验收门」再进下一阶段。
> **本计划基于 2026-09-14 的本机实测**（非文档转述）：所有「现状」条目都有可复现证据，命令与输出见 §0。

**Goal:** 把 `D:\Program\Github\dsh-bio-graft` 做成 genie 生态里**契约完整、零自愈、可审计**的基因编辑域插件（`graft_*`，`@dsh-bio/dsh-bio-graft`），并把它的编辑设计能力从「nuclease 枚举 + 打分向量」扩展到**可信脱靶语义层 + 声明式排名 + 碱基编辑**，使其成为设计高效基因编辑的专用工具。

**Architecture:** 沿用家族「感知式域插件」形态（`dsh-plugin-development/references/multi-plugin-host-domain-composition.md`）：graft 独立发布、独立生命周期；实现 hosted-domain integration 协议 v2（`health` / `v1/status`）；genie 侧用**声明式域注册表**（把现有 gem 专用适配器提炼为 `DOMAINS` 描述符 + 通用函数，gem 现有测试作为零漂移回归网）托管「基因编辑设计」条件分页，并在 `prompts/persona.md` 增加存在性感知路由段；跨插件资产契约（EditPlan `.editplan.json`）写进 `genie/docs/plugin-integration.md` v3。

**Tech Stack:** TypeScript/ESM（Cordis 插件层，Node ≥20）、Python 3.12 标准库 +（第二层）可选第三方（走 genie 自举 venv）、Cas-OFFinder v2.4.1（BSD-3，外部二进制不 bundle）、Node `test/*.mjs` 冒烟/契约测试、真实 dsh 0.1.5-rc.1 会话做 E2E。

**版本纪律：** npm 版本**只递增 patch**（0.1.1 → 0.1.2 …），README 里的能力批次叫「批次 A/B/C」，不要写成 v0.2/v0.3 这类版本号。

// test/harness.mjs — graft 测试公共工具（零第三方依赖）
// 纪律：① 不用 process.exit()（管道下会截断 stdout），用 process.exitCode
//       ② strict 模式下探针/跳过必须变成 FAIL（GRAFT_STRICT=1）
import { spawn, spawnSync } from 'node:child_process'
import { existsSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'
import os from 'node:os'

export const REPO = join(dirname(fileURLToPath(import.meta.url)), '..')
export const PYDIR = join(REPO, 'python')
export const STRICT = process.env.GRAFT_STRICT === '1'

let passed = 0
let failed = 0
const failures = []

export function check(name, cond, detail = '') {
  if (cond) { passed += 1; console.log(`  ok   ${name}`) }
  else { failed += 1; failures.push(name); console.log(`  FAIL ${name} ${detail}`) }
}

export function summary(label) {
  console.log(`\n${label}: ${passed} passed, ${failed} failed`)
  if (failed) {
    console.log('failed cases:\n  - ' + failures.join('\n  - '))
    process.exitCode = 1
  }
  return failed === 0
}

export function skip(name, reason) {
  if (STRICT) return check(name, false, `(skipped: ${reason}; GRAFT_STRICT=1 forbids silent skips)`)
  console.log(`  skip ${name} (${reason})`)
  return true
}

function pythonCandidates() {
  const list = []
  if (process.env.GRAFT_PYTHON) list.push(process.env.GRAFT_PYTHON)
  const dshHome = process.env.DSH_HOME ?? join(os.homedir(), '.dsh')
  list.push(process.platform === 'win32'
    ? join(dshHome, 'dsh-bio-genie', 'python-env', 'Scripts', 'python.exe')
    : join(dshHome, 'dsh-bio-genie', 'python-env', 'bin', 'python'))
  if (process.env.CONDA_PREFIX) {
    list.push(process.platform === 'win32'
      ? join(process.env.CONDA_PREFIX, 'python.exe')
      : join(process.env.CONDA_PREFIX, 'bin', 'python'))
  }
  list.push('python')
  return list
}

export function pythonExe() {
  for (const exe of pythonCandidates()) {
    if (exe !== 'python' && !existsSync(exe)) continue
    const probe = spawnSync(exe, ['-I', '-c', 'import json, re'], { windowsHide: true })
    if (probe.status === 0) return exe
  }
  throw new Error('no usable python interpreter (set GRAFT_PYTHON)')
}

/** 直驱 graft_ops.py：返回解析后的 result（失败抛错并携带 stderr 尾部）。 */
export function op(opName, args = {}, { timeoutMs = 120_000 } = {}) {
  const py = pythonExe()
  const res = spawnSync(py, ['-I', join(PYDIR, 'graft_ops.py')], {
    cwd: PYDIR,
    input: JSON.stringify({ op: opName, args }),
    encoding: 'utf8',
    timeout: timeoutMs,
    windowsHide: true,
    maxBuffer: 64 * 1024 * 1024,
  })
  const err = res.stderr || ''
  if (err.includes('Traceback (most recent call last)')) {
    throw new Error(`op ${opName} traceback: ${err.slice(-600)}`)
  }
  const line = (res.stdout || '').trim().split(/\r?\n/).filter(Boolean).pop()
  if (!line) throw new Error(`op ${opName} produced no output; stderr=${err.slice(-300)}`)
  const parsed = JSON.parse(line)
  if (parsed.ok !== true) throw new Error(`op ${opName} ok:false -> ${parsed.error}`)
  return parsed.result
}

"""sequtil.py — 序列规范化（graft 内共享；与 bio-genie 的 python/seq_util.py 同族契约但
不跨包 import：两个插件是独立 npm 包）。

为什么单独成模块：guides.py / 未来的 base_edit.py / offtarget 的 genome 预检都需要同一套
清洗规则；graft 的硬教训是「同一个事实只能有一处实现」。
"""
from __future__ import annotations

_REVCOMP = str.maketrans('ACGTNRYKMSWBDHVacgtnrykmswbdhv',
                         'TGCANYRMKSWVHDBtgcanyrmkswvhdb')


def revcomp(seq: str) -> str:
    """反向互补（IUPAC 感知；小写→小写，未知字符原样保留由调用方校验）。"""
    return seq.translate(_REVCOMP)[::-1]


def split_fasta(raw: str) -> list[tuple[str, str]]:
    """把（可能多条的）FASTA/裸序列切成 [(record_id, sequence), ...]。

    record_id 对裸序列是 None。
    """
    text = raw.replace('\r\n', '\n').replace('\r', '\n')
    records: list[tuple[str, str]] = []
    current_id: str | None = None
    chunks: list[str] = []

    def flush():
        if chunks:
            seq = ''.join(''.join(chunks).split()).upper()
            if seq:
                records.append((current_id, seq))

    for line in text.split('\n'):
        stripped = line.strip()
        if stripped.startswith('>'):
            flush()
            chunks = []
            current_id = stripped[1:].split()[0] if stripped[1:].strip() else None
            continue
        if stripped:
            chunks.append(stripped)
    flush()
    return records


def clean_sequence(raw: str, *, record: int = 0, allow_multiple: bool = True
                   ) -> tuple[str, str | None, int]:
    """把 FASTA / 裸序列 / 多行序列统一成 (大写单串, record_id, n_records)。

    历史缺陷（2026-09-14 修复）：旧实现先 `''.join(sequence.split())` 去掉换行，
    再用 `^>[^\\n]*\\n?` 剥头行 —— 换行已不存在，`[^\\n]*` 贪婪吃掉整条序列，
    于是**任何 FASTA 输入**都报 `empty sequence after cleaning`（实测复现）。
    """
    if raw is None or not str(raw).strip():
        raise ValueError('sequence required (raw DNA or FASTA)')
    records = split_fasta(str(raw))
    if not records:
        raise ValueError('empty sequence after cleaning')
    if len(records) > 1 and not allow_multiple:
        raise ValueError(f'multi-record FASTA not allowed (got {len(records)} records)')
    if record >= len(records):
        raise IndexError(f'record index {record} out of range (n_records={len(records)})')
    seq, rid = records[record][1], records[record][0]
    return seq, rid, len(records)
```

def pam_match(pam_pattern: str, seq: str, at: int) -> int | None:
    """在 seq 的 at 位置按 IUPAC 语义匹配 PAM。

    历史缺陷（2026-09-14 修复）：旧实现只把 'N' 当通配符，其余字符按字面量比 ——
    Cas12a 的 'TTTV' 中的 V（=A/C/G）永远匹配不上 → 整个编辑器恒返回 0 候选（实测）。
    未知 IUPAC 符号一律**响亮失败**（PAM 定义错不应静默变成「无候选」）。
    """
    s = seq.upper()
    p = pam_pattern.upper()
    if at < 0 or at + len(p) > len(s):
        return None
    for i, code in enumerate(p):
        allowed = _IUPAC.get(code)
        if allowed is None:
            raise ValueError(f'unknown IUPAC code {code!r} in PAM pattern {pam_pattern!r}')
        if s[at + i] not in allowed:
            return None
    return len(p)
```

function statusCheck(id, status, detail) { return { id, status, detail } }

export function createIntegrationService() {
  let cached = null
  let cachedAt = 0
  return {
    async health() {
      return { ok: true, value: {
        pluginId: 'dsh-bio-graft',
        pluginVersion: PLUGIN_VERSION,
        protocolMajor: PROTOCOL_MAJOR,
        protocolMinors: PROTOCOL_MINORS,
        features: INTEGRATION_FEATURES,
      } }
    },
    async status() {
      if (cached && Date.now() - cachedAt < RUNTIME_PROBE_CACHE_MS) return cached
      const dataRoot = defaultDataRoot()
      const plans = listFiles(join(dataRoot, 'plans'), (n) => n.endsWith('.editplan.json'))
      const casExe = join(dataRoot, 'bin', 'cas-offinder.exe')
      const py = pythonCandidates()
      const checks = [
        statusCheck('python.interpreter', py.length ? 'ok' : 'missing',
          `候选解释器 ${py.length} 个，首选 ${py[0]?.path ?? '—'}（source=${py[0]?.source ?? '—'}）`),
        statusCheck('runtime.casoffinder', existsSync(casExe) ? 'ok' : 'missing',
          existsSync(casExe) ? casExe : '未安装：agent 调 graft_backend_status(action=ensure) 自动获取 BSD-3 二进制'),
        statusCheck('plans.dir', existsSync(join(dataRoot, 'plans')) ? 'ok' : 'warn',
          join(dataRoot, 'plans')),
      ]
      const value = { ok: true, value: {
        state: checks.every((c) => c.status === 'ok') ? 'ready' : 'degraded',
        generatedAt: new Date().toISOString(),
        pluginVersion: PLUGIN_VERSION,
        features: INTEGRATION_FEATURES,
        checks,
        data: {
          plans: { count: plans.length, items: plans.slice(0, 50), dir: join(dataRoot, 'plans') },
          editors: EDITOR_SUMMARY,      // 由 editors 模块导出的静态摘要（不 spawn python）
          backend: { casOffinder: { present: existsSync(casExe), path: existsSync(casExe) ? casExe : null } },
        },
        env: { interpreter: py.length ? { selected: py[0].path, source: py[0].source,
                                          candidates: py.map((c) => ({ path: c.path, source: c.source })) } : null },

/** 模块解析优先（正确处理 pnpm 符号链接与 hoisting），失败回退同级目录。 */
export function detectDomain(domain) {
  const require = createRequire(import.meta.url)
  try {
    const pkgPath = require.resolve(`${domain.packageName}/package.json`)
    const pkg = JSON.parse(readFileSync(pkgPath, 'utf8'))
    return { installed: true, version: pkg.version, pluginDir: dirname(pkgPath), detectedBy: 'module-resolve' }
  } catch { /* fallthrough */ }
  try {
    const sibling = join(dirname(fileURLToPath(import.meta.url)), '..', '..', domain.dataRootName, 'package.json')
    const pkg = JSON.parse(readFileSync(sibling, 'utf8'))
    return { installed: true, version: pkg.version, pluginDir: dirname(sibling), detectedBy: 'sibling-path' }
  } catch {
    return { installed: false, detectedBy: 'none' }
  }
}

const CHECK_STATUSES = new Set(['ok', 'warn', 'missing', 'error'])

function hasValidStatus(domain, status) {
  if (!status || !['ready', 'degraded'].includes(status.state) || !Array.isArray(status.checks)) return false
  if (!status.checks.every((c) => typeof c?.id === 'string' && CHECK_STATUSES.has(c.status))) return false
  if (!domain.requiredCheckIds.every((id) => status.checks.some((c) => c.id === id))) return false
  return status.state === (status.checks.some((c) => c.status !== 'ok') ? 'degraded' : 'ready')
}

/** 六态判定（gem 原实现逐字迁移；graft 复用同一规则）。 */
export function classifyDomainState(domain, { probe, health, status } = {}) {
  if (!probe?.installed) return { state: 'not-installed', installed: false }
  if (isVersionBelow(probe.version, domain.minIntegrationVersion)) {
    return { state: 'legacy', installed: true, version: probe.version,
             minimumVersion: domain.minIntegrationVersion }
  }
  if (health?.protocolMajor !== undefined && health.protocolMajor !== domain.protocolMajor) {
    return { state: 'incompatible', installed: true, version: probe.version,
             protocolMajor: health.protocolMajor, expectedProtocolMajor: domain.protocolMajor }
  }
  if (health?.protocolMajor === domain.protocolMajor && hasValidStatus(domain, status)) {
    return { state: status.checks.some((c) => c.status !== 'ok') ? 'degraded' : 'ready',
             installed: true, version: probe.version, checks: status.checks }
  }
  return { state: 'installed-unavailable', installed: true, version: probe.version }
}

### 10.2 权衡说明

- **为什么把「脱靶语义层」排在「碱基编辑」前**：脱靶当前是**坏的**（D3）且是信任基石（写进任何报告都要用）；碱基编辑是新增能力，晚一批代价小。
- **为什么拆 `graft_rank` 而不是让 agent 自己排**：E2E 证据显示 agent 会手算排序策略（`session-ab890f70` 里 2 次 `bio_python` 纯做统计/排序）；工具化后策略可审计、可复现，且**不再产生「agent 心算数字」这类幻觉入口**。
- **为什么不实现发表的效率模型（Rule Set 2 等）**：权重表转述易错、版本漂移、且一旦被引用就会变成「验证过的预测器」的口径。保持「特征向量 + 声明式 objective + external provider 槽位」是诚实上限。
- **为什么 panel 走 genie 托管**：契约 §4 明确「面板一级入口与子页 UI → genie」；域插件自建面板会造成 UI 碎片化与所有权混乱。

### 10.3 待用户拍板的开放问题（不阻塞 A/B 批）

1. **`bio_crispr_guide` 的终局**：长期是否下线（把 CRISPR 设计彻底交给 graft）？我倾向**保留为轻量兜底**（未装 graft 的用户仍有基本能力），只在 persona/description 里降级并标注分数性质。

3. **碱基编辑窗口的文献校对**：由谁做一手文献核对（我可以查 PubMed 并给出 PMID/原文数字；用户也可指定其他来源）。
