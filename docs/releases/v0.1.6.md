# @dsh-bio/dsh-bio-graft v0.1.6

> **主题**：编辑设计细节修复批次 + 公开文档整理。
> 基因编辑设计专科插件：11 个语义化工具（sgRNA 候选 / 评分向量 / 脱靶扫描 / 策略评估 / 验证方案 / EditPlan 账本）。

## 修复与改进

**编辑设计语义**
- 碱基编辑坐标语义显式化：`codon_index` 明确标注 0-based；新增 `codon_number_1based` 字段，消除「第几个密码子」歧义。
- `graft_score` 输出 schema 放宽；策略/评分字段补充适用性标注。

**脱靶扫描（安全相关）**
- 修复带返回上限的扫描把「未读取」显示成「零命中」的问题——`n_hits` 恒为全量计数（另附 `hits_truncated` 标志与截断列表），杜绝假「无脱靶」结论。

**输入与运行环境**
- `guide_enumerate` / `base_edit` 的 `sequence` 参数支持文件路径输入。
- 工具相对路径基于会话工作区解析（python 子进程 cwd 对齐会话目录）。
- 解释器 / 后端探测语义与查找链加固。

**公开文档整理**
- 清理内部流程信息；英文 README 状态同步更新。

## 安装

```sh
dsh plugin --profile web add @dsh-bio/dsh-bio-graft
# 或经 npx：npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-graft
```

桌面端（0.2.0+）：用桌面端自带 CLI（`--profile desktop`）或应用内「插件」页安装。

## 已知边界（诚实清单）

- Cas-OFFinder 后端仅 Windows 自动获取（v2.4.1 稳定版）；其他平台手动放置。
- 无 CPU OpenCL 设备的机器上只能走 GPU（`device=auto` 已自动处理）。
- 编辑器几何证据状态见 `docs/PROFILES-TODO.md`（未核编辑器如实标注）。
