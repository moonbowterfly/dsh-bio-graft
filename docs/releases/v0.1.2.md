# @dsh-bio/dsh-bio-graft v0.1.2

> **首个 npm 发布版本** —— 0.1.0 / 0.1.1 未发布到 npm，本版涵盖全部改动。
> 基因编辑设计域插件：dsh-bio 家族第三个成员（genie = 宿主 / gem = 代谢模型 / **graft = 序列编辑**）。

## 亮点

**10 个语义化工具**（全部纯标准库 Python，装完即用，无需额外准备）

| 工具 | 一句话 |
|---|---|
| `graft_profiles` | 编辑酶注册表（PAM/spacer/几何 + **证据分级**）与碱基编辑器（五层 profile，窗口带文献与计数约定） |
| `graft_design` | PAM 双向扫描 → 候选 + 评分向量 + **切割位点**（含口径与 verified） |
| `graft_score` | 候选评分向量（不打综合分） |
| `graft_rank` | **声明式排名**：pareto / 字典序 / 显式加权；`policy_id`+`policy_digest` 随结果进账本 |
| `graft_offtarget` | Cas-OFFinder 脱靶扫描 → 结构化命中 + **`search_completeness`**（枚举没搜的维度）+ `per_guide` 汇总 |
| `graft_base_edit` | **碱基编辑设计**（BE3/BE4max/ABE7.10）：窗口内可编辑碱基 + **bystander** + 密码子后果 + 链语义三件套 |
| `graft_strategy` | **多 guide 策略**：`deletion_pair` 预测缺失区间/连接点/移码；`paired_nickase` 配对；每对附 **pairwise 脱靶组合**（风险不相加）；未实现策略显式拒绝 |
| `graft_backend_status` | 后端探测 / OpenCL 设备列表 / 自动安装 |
| `graft_plan_save` / `graft_plan_load` | **EditPlan 可审计账本**（append-only runs，run 号单调只增） |

**计算结果可信度是产品的一部分**
- 脱靶结论**永不说「安全」**：结构化 `assessment.safety_conclusion` 恒为 `not_supported`，
  0 命中给排查提示；`search_completeness` 明确列出**没搜**的维度（bulge / 结构变异 / 样本变异）。
- **不打综合分**：只给评分向量 + 声明式策略；`weighted` 必须显式给权重且带 disclaimer。
- **负证据语义**：`0` / `null` / `not_searched` 严格区分；数据缺失时硬过滤会剔除并说明，
  「没有报错」不等于「做过分析」。
- **几何 ≠ 效率**：窗口内只推「几何兼容」；编辑器几何未核一手文献的（Cas12b/Cas13a）如实标注，
  效率预测一律留给 external provider。

**与宿主 genie 的接入**（hosted-domain integration 协议 v2）
- genie 设置面板托管「**基因编辑设计**」条件分页（状态 / 脱靶后端 / 解释器 / **编辑器注册表含证据分级** /
  EditPlan 账本 / 修复责任方）；未安装时不出现空壳 UI。
- genie 的 persona 路由让 agent 把编辑设计任务导向 `graft_*`（实测：0 次回落到轻量工具）。

## 安装

```bash
dsh plugin --profile web add @dsh-bio/dsh-bio-graft
```

脱靶扫描需要 Cas-OFFinder（BSD-3 外部二进制）：`graft_backend_status(action="ensure")` 自动获取（仅 Windows）。

## 验证

- **145 断言**本地测试网（含**真实 Cas-OFFinder 夹具**：精确命中坐标、错配位置、seed 区命中、0 命中护栏）
  → `npm test`；`GRAFT_STRICT=1` 严格模式同样全绿。
- **零依赖验证**：从 npm 包安装后用**裸 Python 3.11**（非任何自建环境）跑 op，4/4 通过。
- **真实 agent 会话**（5 轮）：修复前的缺陷被会话抓出并在插件层根治（编码契约、branch 型工具 execute、
  排名形态容错等），每轮均有前后对照与事件归档。

## 已知边界（诚实清单）

- **未实现**：prime editing、HDR 供体设计、CRISPRi/a、Cas13 designer、编辑结果 ML 预测
  （最后一项一律 external provider；FlashFry/PrimeDesign/inDelphi/CRISPResso2 均不 bundle）。
- 碱基编辑器窗口目前仅 **BE3 / BE4max / ABE7.10**（均经一手文献核对）；其余编辑器待核后再入册。
- **Cas12b / Cas13a** 的 PAM 与几何**未核一手文献**，报告里必须注明（`verified=false`）。
- Cas-OFFinder **bulge 搜索不受支持**（官方需独立包装脚本）——请求 bulge 会响亮报错，绝不静默忽略。
