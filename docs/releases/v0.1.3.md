# @dsh-bio/dsh-bio-graft v0.1.3

> **首个 npm 发布版本** —— 0.1.0–0.1.2 未发布到 npm，本版涵盖全部改动（含 0.1.2 的所有内容与 0.1.3 审计修复轮）。
> 基因编辑设计域插件：dsh-bio 家族第三个成员（genie = 宿主 / gem = 代谢模型 / **graft = 序列编辑**）。

## 亮点

**11 个语义化工具**（其中 10 个纯标准库 Python，装完即用；脱靶扫描需 Cas-OFFinder 外部二进制，可自动获取）

| 工具 | 一句话 |
|---|---|
| `graft_profiles` | 编辑酶注册表（PAM/spacer/几何 + **证据分级**）与碱基编辑器（五层 profile，窗口带文献与计数约定） |
| `graft_design` | PAM 双向扫描 → 候选 + 评分向量 + **切割位点**（含口径与 verified） |
| `graft_score` | 候选评分向量（不打综合分） |
| `graft_rank` | **声明式排名**：pareto / 字典序 / 显式加权；`policy_id`+`policy_digest` 随结果进账本 |
| `graft_offtarget` | Cas-OFFinder 脱靶扫描 → 结构化命中 + **`search_completeness`**（枚举没搜的维度）+ `per_guide` 汇总 |
| `graft_base_edit` | **碱基编辑设计**（BE3/BE4max/ABE7.10）：窗口内可编辑碱基 + **bystander** + 密码子后果 + 链语义三件套 |
| `graft_strategy` | **多 guide 策略**：`deletion_pair` 预测缺失区间/连接点/移码；`paired_nickase` 配对；每对附 **pairwise 脱靶组合**（风险不相加）；未实现策略显式拒绝 |
| `graft_validation_plan` | **验证方案**：按模态+宿主分档（required 不可删）+ 指标带分子/分母/assay + `cannot_conclude`；植物加嵌合/合子性/可遗传 |
| `graft_backend_status` | 后端探测 / OpenCL 设备列表 / 自动安装 |
| `graft_plan_save` / `graft_plan_load` | **EditPlan 可审计账本**（append-only runs，run 号单调只增） |

**0.1.3 审计修复轮（本版新增）**
- `graft_rank` 目标轴缺失 **fail-closed**：未分析指标不再以零成本参与排序（weighted 下不再"缺失者排第一"；pareto dominance 增加"任一轴不可比较即不得支配"兜底）；三种策略口径一致，缺失原因随 excluded 写明。
- `graft_base_edit` `strand:'-'` 修复：此前只扫正链再过滤成空结果，现在真正枚举反链；返回体新增 `strand_requested` 自证。
- `graft_strategy` `single_cut` 支持单候选（最低候选数按策略分支）。
- `graft_rank` `homopolymer_max` 扁平形态回退 + 契约单一来源 `rank-contract.json`（schema/帮助/Python/测试同源防漂移）。
- 测试门禁加固：harness 对子进程非零退出 fail-closed、Cas-OFFinder 发现链三路径覆盖、缺后端显著 SKIP。`npm test` 204 断言全绿。

**计算结果可信度是产品的一部分**
- 脱靶结论**永不说「安全」**：结构化 `assessment.safety_conclusion` 恒为 `not_supported`，0 命中给排查提示；`search_completeness` 明确列出**没搜**的维度。
- **不打综合分**：只给评分向量 + 声明式策略；`weighted` 必须显式给权重且带 disclaimer。
- **负证据语义**：`0` / `null` / `not_searched` 严格区分；数据缺失硬过滤剔除并说明。
- **几何 ≠ 效率**：窗口内只推「几何兼容」；编辑器几何未核一手文献的（Cas12b/Cas13a）如实标注 `verified=false`。

**引擎兼容（2026-09-19）**：经 dsh **0.1.5-rc.2** 走廊逐卡走查（55 张变更卡：零适配命中）与实机验证（工具注册 / 域面板 / Cas-OFFinder 就绪）。

## 安装

```sh
dsh plugin --profile web add @dsh-bio/dsh-bio-graft
# 或：npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-graft
```

- 安装后**重启 dsh web**。
- 脱靶扫描后端：`graft_backend_status(action="ensure")` 自动获取（仅 Windows）；其他平台手动放置或设 `GRAFT_CAS_OFFINDER` 环境变量；无后端时扫描相关测试/工具显式标记不可用（绝不静默冒充已验证）。
- 与宿主 `dsh-bio-genie` 同实例共存；BioGenie 设置面板「基因编辑设计」分页显示本插件运行时状态（需宿主 ≥0.6.24）。

## 验证口径

- `npm test` 204 断言全绿（8 套件：工具契约/黄金 op/脱靶扫描/排名/碱基编辑/策略/验证方案/集成契约）。
- 实机 E2E：全新 dsh 环境安装 → 11 工具注册 → graft_profiles/graft_design/graft_plan_save 真实会话链路 → 面板「已安装 · 协议就绪」。

## 已知边界（诚实清单）

- 脱靶扫描依赖 Cas-OFFinder（外部二进制 + OpenCL）：无可用后端时相关能力显式不可用（含 install_hint）。
- prime_edit / HDR / multiplex 等策略未实现——被问及时**显式拒绝**并给出可行替代，不产出假设计。
- 评分向量不含效率预测；活性/效率一律 external provider。
- EditPlan 为本地 append-only 文件账本（`~/.dsh/dsh-bio-graft/plans/`），非数据库。
